# 任务定义与物体清单

## 1 任务

桌面摆放三到四类小物体，位置与朝向随机，机械臂逐件抓取并按类别放入对应格口。

## 2 工作区布局

以下参数在实验台上实测后填写。

- 外部相机相对工作区坐标
- 工作区边界
- 分拣盒格口位置
- 机械臂底座位置

## 3 物体清单

物体以实际可抓取性为准，筛选标准为夹爪能稳定抓起、腕部相机可见、外部相机可见。抓不稳的物体剔除并记录原因。

## 4 成功判据

成功指物体被抓取并放入正确类别格口，放稳后不掉落。失败分为未抓起、掉落、放错格口与策略异常四类。
