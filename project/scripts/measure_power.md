# 能耗测量操作说明

## 设备

- USB-C 功率计 ×1（串接 Pi 5 电源线）
- 功率计 ×1（串接机械臂 12V 电源线，若功率计支持）
- 记录方式：功率计数字显示（人工读数）或上位机日志导出

## 步骤

1. 功率计串接在电源与设备之间，确认读数正常；
2. 每个配置（teacher_gpu / tinyact_fp32 / tinyact_int8 / closed_loop_int8）跑 10 次试次；
3. 每次试次记录：起始总能耗（Wh）、结束总能耗（Wh）、试次数；
4. 用 energy_analysis.py 计算每件能耗（J/件 = ΔWh×3600/件数）。

## 注意

- 读数时确保设备处于稳定工作状态；
- 功率计单位务必统一（Wh 或 kWh），分析脚本默认 Wh。
