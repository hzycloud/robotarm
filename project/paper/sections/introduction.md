# Introduction（初稿）

## 背景

工业与桌面场景的低成本机械臂正从"预编程执行"走向"数据驱动学习"。TinyML 与边缘计算使得在资源受限设备上完成实时感知与决策成为可能，但多数现有系统的闭环能力与可复现性不足。

## 基线工作及其瓶颈

Hu 等（Eng. Proc. 2025, 92, 74）在 UR5 平台上集成 TinyML 与边缘计算实现多物体识别与抓取，报告识别平均 7.6 秒、抓取平均 14.6 秒、识别准确率约 99%。该系统存在七个瓶颈：

1. 识别阶段毫秒级需求与 7.6 秒实际时延之间的巨大差距；
2. 开环执行，无抓取结果验证与纠错；
3. Edge Impulse 黑盒工具链，方法不可完全复现；
4. 仅 4 类简单几何形状，任务复杂度低；
5. 数据集规模小（690 张图片）；
6. UR5 平台成本高，不符合低成本升级叙事；
7. 未报告能耗数据，无法支撑 TinyML 的"低功耗"主张。

## 本文工作

本文提出 Edge-Sort：在低成本 SO-ARM101 六轴机械臂 + Raspberry Pi 5 上实现端到端闭环分拣。四个贡献：

1. TinyACT：缩容 ACT 学生策略 + 离线动作蒸馏 + int8 量化部署，单步推理目标 ≤200ms；
2. 闭环抓取验证器与重试机制，将开环演示系统升级为闭环自主系统；
3. 能耗-时延联合基准（J/件、周期时间、推理时延分解），量化边缘部署收益；
4. 开源 SO-Sort 数据集（LeRobot 格式）与代码，保证可复现性。
