# 结论

本文在低成本 SO-ARM101 六轴机械臂与 Raspberry Pi 5 上实现了端到端闭环桌面分拣系统 Edge-Sort。通过 TinyACT 缩容策略、离线动作蒸馏与 int8 量化，模仿学习策略得以部署到边缘 CPU。通过腕部相机抓取验证器与重试机制，开环演示系统升级为闭环自主系统。通过能耗与时延联合基准，边缘部署的真实收益得到量化。开源数据集与代码保证了研究的可复现性。

未来工作包括三个方面。第一，将伺服控制层下沉到 RP2040 硬实时控制器，Pi 5 仅保留感知与决策，解决 Linux 调度抖动问题。第二，将 SO-Sort 扩展为多任务与多场景基准，覆盖遮挡、光照变化与仿真到真机迁移。第三，探索视觉语言动作模型在端侧的低比特蒸馏部署。
