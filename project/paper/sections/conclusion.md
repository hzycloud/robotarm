# Conclusion（初稿）

本文在低成本 SO-ARM101 六轴机械臂与 Raspberry Pi 5 上实现了端到端闭环桌面分拣系统 Edge-Sort。通过 TinyACT 缩容策略、离线动作蒸馏与 int8 量化，将模仿学习策略部署到边缘 CPU；通过腕部相机抓取验证器与重试机制，将开环演示系统升级为闭环自主系统；通过能耗-时延联合基准，量化了边缘部署的真实收益。开源数据集与代码保证了可复现性。

未来工作：

1. 将伺服控制层下沉到 RP2040 硬实时控制器（Pi 5 仅保留感知/决策），解决 Linux 调度抖动；
2. 扩展 SO-Sort 为多任务/多场景基准（遮挡、光照、仿真 sim-to-real）；
3. 探索 VLA 模型在端侧的低比特蒸馏部署。
