# Cover Letter（初稿，投稿前按编辑要求微调）

Dear Editor,

We are pleased to submit our manuscript entitled "Edge-Sort: Closed-Loop Desktop Sorting via Tiny Distilled ACT Policies on a Low-Cost Edge Robotic Arm" for consideration in IEEE Sensors Journal.

This work addresses the gap between demonstration-level TinyML robotic systems and deployable edge autonomy. Compared with prior work that reported 7.6 s recognition and 14.6 s open-loop grasping on a UR5 (Eng. Proc. 2025, 92, 74), we present a closed-loop sorting system on a low-cost SO-ARM101 arm with a Raspberry Pi 5: (1) a distilled and int8-quantized TinyACT policy achieving real-time inference on edge CPU; (2) a grasp verifier with automatic retry; (3) an energy-latency benchmark quantifying edge deployment benefits; and (4) an open-source dataset in LeRobot format.

The topic fits the journal's scope on embedded sensors, machine learning, and robotics systems. All experiments were conducted on physical hardware; data and code will be released upon acceptance.
