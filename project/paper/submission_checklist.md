# 投稿前检查清单

## 1 稿件规范

- 使用 IEEE Sensors Journal 官方 LaTeX 或 Word 模板，页数与字数符合限制
- 图表清晰，分辨率不低于 300dpi，图注完整
- 英文润色完成
- 自检查重通过

## 2 内容完整性

- Data Availability 写明 Hugging Face 数据集与 GitHub 仓库链接，并确认可访问
- 引用基线论文并注明平台差异
- 导师确认为通讯作者，署名顺序确认

## 3 投稿材料

- cover letter
- 稿件主文件
- 补充材料（如视频链接）

## 4 目标期刊

首选 IEEE Sensors Journal。若被拒，按审稿意见修改后转投 IEEE TIM 或 Neurocomputing。
