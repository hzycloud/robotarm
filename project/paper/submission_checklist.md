# 投稿前检查清单

- [ ] 使用 IEEE Sensors Journal 官方 LaTeX/Word 模板，页数/字数符合限制
- [ ] 图表清晰，分辨率 ≥300dpi，图注完整
- [ ] Data Availability 写明 Hugging Face 数据集与 GitHub 仓库链接（可访问）
- [ ] 引用基线论文并注明平台差异（UR5 vs SO-ARM101）
- [ ] 导师确认为通讯作者，署名顺序确认
- [ ] 英文润色（可请导师/润色服务）
- [ ] 自检查重
- [ ] 上传 cover letter、稿件、补充材料（如视频链接）
- [ ] 目标：IEEE Sensors Journal；拒稿后按意见修改转投 IEEE TIM 或 Neurocomputing
